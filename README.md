# Keräysvahti (keraysvahti.fi)

Hakupalvelu Poliisihallituksen voimassa olevista rahankeräysluvista: haku nimellä, keräysnumerolla, Y-tunnuksella ja tilinumerolla.

- `index.html` – sivusto (GitHub Pages)
- `luvat.json` – poliisin PDF-listasta luettu data (lähde: Poliisihallitus, Lista-rahankerayksista-FI.pdf)
- Päivitys: lue uusi PDF skriptillä `lue-pdf.py` (repo Miksu900/krypto, kansio keraykset/) ja korvaa `luvat.json`.
